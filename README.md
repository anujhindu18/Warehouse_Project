# Warehouse_Project

Warehouse Data Analysis Project using SQL Server, Excel, and Power BI to analyze inventory, stock levels, and warehouse performance.

## Tools
- SQL Server (SSMS)
- Excel
- Power BI

## Progress — November 2, 2026
- Created `Warehouse` database and Bronze, Silver, and Gold schemas.
- Developed the `bronze.load_bronze` stored procedure.
- Added CRM and ERP CSV loading using `BULK INSERT`.
- Implemented error handling and load-duration tracking.
- Created the Bronze Layer data flow diagram.

## Next Steps

- Clean data in the Silver Layer.
- Build Gold Layer tables and Power BI dashboards.
